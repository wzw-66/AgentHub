  Agent Market 设计方案

  核心流程

  发布者:  创建 Agent → 一键发布至市场 → 管理已发布的 listing
  使用者:  浏览市场 → 查看详情 → 一键导入 → 在自己的联系人中使用

  数据模型

  新增 PublishedAgent 表，与 Contact 解耦，发布时拍 snapshot：

  model PublishedAgent {
    id           String        @id @default(cuid())
    name         String
    description  String?
    avatarUrl    String?
    provider     AgentProvider
    systemPrompt String?
    model        String?
    config       Json?           // Custom provider 的 API 配置等
    tags         String[]        @default([])
    importCount  Int             @default(0)
    createdAt    DateTime        @default(now())
    updatedAt    DateTime        @updatedAt

    creatorId    String
    creator      User            @relation(…)

    @@index([creatorId])
    @@index([name])
    @@index([provider])
  }

  选 snapshot 而非引用 Contact 的原因：发布后的 listing 独立于原始
  Agent，修改/删除原始 Agent 不影响已发布的配置。
