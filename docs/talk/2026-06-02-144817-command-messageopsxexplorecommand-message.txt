  建议方案

  方案一：Markdown 渲染

  添加 react-markdown + remark-gfm：

  pnpm --filter @agenthub/web add react-markdown remark-gfm

  在 ChatPanel.tsx 中把 MessageContent 改为：

  import ReactMarkdown from "react-markdown";
  import remarkGfm from "remark-gfm";

  function MessageContent({ message }: { message: Message }) {
    const { isCode, code, language } = isCodeBlock(message.content);
    if (isCode) {
      return <CodeBlock code={code} language={language} />;
    }
    return (
      <ReactMarkdown
        remarkPlugins={[remarkGfm]}
        components={{
          code({ className, children, ...props }) {
            const isInline = !className; // no language class = inline code
            if (isInline) {
              return (
                <code className="...inline-code-style..." {...props}>
                  {children}
                </code>
              );
            }
            return <CodeBlock code={String(children)} language={(className || 
  "").replace("language-", "")} />;
          },
        }}
      >
        {message.content}
      </ReactMarkdown>
    );
  }

  这样同时支持：内联代码、加粗、标题、列表、表格等所有 GFM markdown 语法。

● 你说得对！我重新看了一下代码，确实有个结构层面的 bug。

  先看实际的 DOM 层级：

  <div className="flex flex-col gap-3">       ← flex 容器
                                                │
    <div className="relative ... message-bubble group">  ← flex 子项（占满整宽）
      ↓
      <MessageBubble variant="user">          ← 里面的 alignSelf 没意义了
        style={{ alignSelf: "flex-end" }}     ← ❌ 这个不生效！
      </MessageBubble>

    <div className="relative ... message-bubble group">  ← flex 子项
      ↓
      <MessageBubble variant="contact">
        style={{ alignSelf: "flex-start" }}   ← ❌ 同样不生效！
      </MessageBubble>

  问题根因：ChatPanel.tsx 第 287-293 行，每个消息外面包了一层 <div 
  className="relative animate-fade-in-up message-bubble group">。这个 wrapper
  div 成了 flex 容器的直接子项，所以 alignSelf 应该加在 wrapper 上才有效。而
  MessageBubble 内部的 alignSelf 只是相对于 wrapper 定位，但 wrapper 本身不是
  flex 容器，所以 alignSelf 在 MessageBubble 上完全不生效。

  结果就是两个 wrapper 都占满整宽 (stretch)，里面的气泡看似都在左边。

  修复方式——在 ChatPanel 里给 wrapper 加上 alignSelf 样式，或者直接让 wrapper
  变成一个 flex 容器：

  // 把 wrapper 改为 flex 容器，让 MessageBubble 内部的 alignSelf 可以生效
  <div key={msg.id} className="relative flex flex-col animate-fade-in-up 
  message-bubble group" ...>

  或者更直接的做法，把对齐搬到 wrapper 层：

  // 直接把 alignSelf 给 wrapper（最简洁）
  <div
    key={msg.id}
    className="relative animate-fade-in-up message-bubble group"
    style={{ alignSelf: variant === "user" ? "flex-end" : "flex-start" }}
  >

● 好，我找到根因了。问题在于 MessageBubble 组件本身有 display: flex 
  使其作为块级元素占满父容器宽度，因此外层 wrapper 的 align-items
  无法产生视觉效果。

  MessageBubble 的 outer div:
  style={{ display: "flex", flexDirection: "column", maxWidth: "70%", ... }}

  display: flex 使它成为块级 flex 容器 → 默认占满父容器宽度。maxWidth: 70%
  理论上应限制宽度，但在嵌套 flex 上下文中浏览器渲染不一致。

  正确的解法是避免 flexbox 做对齐，改用更基础的 text-align + inline-block：

  wrapper: position:relative; text-align: right   ← 可靠的水平对齐
    ├── inner-wrapper: display: inline-block; text-align: left; max-width:70%
    │   └── MessageBubble (原样，不改)
    ├── delete confirm (block，不受影响)
    └── hover actions (absolute，不受影响)

  这样不需要动 MessageBubble 组件，也不依赖 flex 嵌套链条，text-align
  在所有浏览器都稳定工作。
