  问题原因 & 修复总结

  根因： 你在 Windows 上，claude 和 opencode 是通过 .cmd
  批处理文件运行的。Node.js 的 spawn 直接执行 .cmd 文件时，Windows
  的批处理语法（特别是 goto 和 title %COMSPEC% 结构）会导致 EINVAL 错误，而通过
  cmd.exe 执行则正常。

  修复内容（3 处改动）：

  1. ClaudeAdapter — spawn 加上 shell: process.platform === "win32"，Windows
  上通过 cmd.exe 启动 CLI
  2. OpenCodeAdapter — 同上
  3. abort() 方法 — Windows 上用 taskkill /PID /T /F 正确杀掉进程树，避免使用
  shell: true 后 cmd.exe 的子进程成为孤儿
