● The issue is clear: the hover buttons use position: absolute + transform: 
  translateX() which places them outside the parent div's bounding box. When the
   mouse tries to move from the message to the buttons, it exits the parent →
  triggers onMouseLeave → buttons disappear before the mouse reaches them.

  The fix: use a flex layout where the button area is a natural child within the
   parent's box, so the hover zone is continuous. The button area uses width: 0
  + min-width: 3px as a permanent hover bridge when hidden.
