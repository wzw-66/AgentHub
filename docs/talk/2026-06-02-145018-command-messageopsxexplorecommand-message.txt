● 找到原因了。看当前的布局结构：

  ┌──────────────────────────────────────────────────────┐
  │ flex-col 消息列表                                     │
  │                                                      │
  │  [outer div: relative, alignSelf: flex-start]        │
  │  ┌──────────────────────────────────────────────────┐│
  │  │ [MessageBubble: maxWidth 70%, left-aligned]      ││
  │  │ ┌─────────────────────┐                          ││
  │  │ │ contact 消息内容     │                          ││
  │  │ └─────────────────────┘                          ││
  │  │                                                  ││
  │  │                      ↩ 📝 🗑  ← absolute right:0 ││
  │  │                          (太远了!)                ││
  │  └──────────────────────────────────────────────────┘│
  └──────────────────────────────────────────────────────┘

  核心问题：position: absolute; right: 0 把图标定位到了整个外层 div 的最右端，而
   contact 气泡是左对齐的（maxWidth 70%）。所以图标离气泡几百像素，很远。

  用户消息没问题，因为用户气泡本身就是右对齐的，right: 0 正好在气泡旁边。

  我的修复方案

  把外层 div 改成 flex row，让气泡和图标天然并排：

  ┌──────────────────────────────────────────────────────┐
  │ flex-col 消息列表                                     │
  │                                                      │
  │  [outer div: flex direction: row, flex-start]        │
  │  ┌──────────────────────────────┐                    │
  │  │ ┌─────────────────────┐ ↩ 📝 🗑│ ← 同排，自然贴近  │
  │  │ │ contact 消息内容     │      │                    │
  │  │ └─────────────────────┘      │                    │
  │  └──────────────────────────────┘                    │
  └──────────────────────────────────────────────────────┘

  改动很小，只需：

  1. contact 消息：外层 div flexDirection: "row"，图标用正常文档流（去掉
  absolute）放在气泡右侧
  2. user/system 消息：保持原样（flexDirection: "column" + absolute 定位不变）

  问题在于现在图标 inline 后，hover 检测还涉及 onMouseEnter/Leave
  的行为。不过因为图标在 div 内部，hover 到图标时不会触发
  mouseleave，所以没问题。
