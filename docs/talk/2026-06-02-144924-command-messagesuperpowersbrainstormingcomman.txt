● 好问题。"Pin" 在赛题里指的是 Pin 关键消息作为长期上下文。

  具体来说：

  Pin 消息 ≠ 置顶对话
  - 置顶对话 = 把整个会话固定在侧边栏顶部（方便快速找回）
  - Pin 消息 = 把某条消息"钉"住，让它一直被包含在传给 Agent 
  上下文中，不会被后续对话冲掉

  场景举例：
  你和 Agent 讨论一个项目，中间确定了"数据库用 PostgreSQL，端口
  5432"这条关键信息。如果 pin
  住这条消息，后续无论聊了多少轮，这条消息都会作为上下文传给
  Agent，不需要反复提醒。
