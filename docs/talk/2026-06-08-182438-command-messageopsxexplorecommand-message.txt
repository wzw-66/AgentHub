  当前交互的问题

         点击 [+]
             ↓
    ┌─────────────────────┐
    │   Sidebar (会话列表)  │
    │                     │
    │   会话1             │
    │   会话2             │

  3. 突兀的弹出层 — 和整体 UI 风格不搭，像临时补丁

  几个设计方向

  我想到几个方向，和你探讨：

  方案 A：Sidebar 视图切换（最像微信）

  默认状态:                          点击 [+] 后:
  ┌──────────┬──────────────┐       ┌──────────┬──────────────┐
  │ 会话列表  │  ChatPanel   │       │ 添加 Agent│  ChatPanel   │
  │          │              │       │          │              │
  │ 会话1    │              │       │ 🔍搜索... │              │
  │ 会话2    │              │       │          │              │
  │ 会话3    │              │       │ ┌──────┐ │              │
  │ ...      │              │       │ │AgentA│ │              │
  │          │              │       │ │AgentB│ │              │
  │ [+]      │              │       │ │AgentC│ │              │
  │          │              │       │ │AgentD│ │              │
  │          │              │       │ │AgentE│ │              │
  └──────────┴──────────────┘       │ │AgentF│ │              │
                                    │ └──────┘ │              │
                                    │  选中: A, C             │
                                    │  [ ＋ 创建群聊 ]        │
                                    │          │              │
                                    └──────────┴──────────────┘

  - Sidebar 在「会话列表」和「添加 Agent」两个视图间切换
  - 点击 "+" 平滑过渡到 Agent 浏览器
  - 有搜索框，可以搜索 agent
  - 点击选中（支持多选），底部显示已选数量和创建按钮
  - 点击返回箭头或 ESC 回到会话列表
  - 优点：交互自然，不突兀，空间充足
  - 优点：和微信肌肉记忆一致，学习成本低

  方案 B：左侧滑出面板

  点击 [+] 后 — 面板从左侧滑出，覆盖 Sidebar + 部分 ChatPanel
  ┌──────────┬──────────┬───────────┐
  │  添加Agent│ 会话列表  │           │
  │          │          │           │
  │ 🔍搜索...│          │           │
  │          │          │           │
  │ Agent A  │          │           │
  │ Agent B  │          │           │
  │ Agent C  │          │           │
  │ Agent D  │          │           │
  │ Agent E  │          │           │
  │ Agent F  │          │           │
  │          │          │           │
  │ [创建群聊]│          │           │
  └──────────┴──────────┴───────────┘

  - 类似 macOS Spotlight / 侧边抽屉效果
  - 覆盖层带半透明 backdrop
  - 优点：不破坏主布局，视觉上有层次感
  - 缺点：压缩了 ChatPanel 的空间

  方案 C：在 ChatPanel 区域打开「新建会话」页面

  点击 [+] 后 — ChatPanel 区域变成 Agent 选择器
  ┌──────────┬──────────────────────────┐
  │ 会话列表  │  新建会话                   │
  │          │  ┌──────────────────────┐ │
  │ 会话1    │  │  🔍 搜索 Agent...    │ │
  │ 会话2    │  ├──────────────────────┤ │
  │ 会话3    │  │                      │ │
  │ ...      │  │  ┌────┐ ┌────┐ ┌───┐│ │
  │          │  │  │ A  │ │ B  │ │ C ││ │
  │          │  │  └────┘ └────┘ └───┘│ │
  │          │  │  ┌────┐ ┌────┐     │ │
  │          │  │  │ D  │ │ E  │     │ │
  │          │  │  └────┘ └────┘     │ │
  │          │  │                    │ │
  │          │  │  [创建群聊]        │ │
  │          │  └────────────────────┘ │
  └──────────┴──────────────────────────┘

  - 把 ChatPanel 当作「页面」来用，类似 web app 的路由
  - 可以展示网格布局、卡片风格
  - 优点：视觉空间最大，设计自由度最高
  - 优点：适合展示 Agent 的详细信息（头像、描述、能力标签）
  - 缺点：ChatPanel 需要一个「空状态」来承载这个视图

  综合设计方案

  把 Sidebar 改造成 多视图模式，像微信左边栏一样切换上下文：

  视图 1：会话列表（默认）

  ┌─────────────────────────┐
  │ AgentHub    [+]  [🤖]   │ ← 🤖 新按钮：查看所有 Agent
  │ 🔍 搜索会话             │
  │                         │
  │ [A][B][C][D] 联系 pills │
  │                         │
  │ ◎ 会话 1               │
  │ ◎ 会话 2               │
  │ ◎ 会话 3               │
  │ ...                    │
  │                         │
  ├─────────────────────────┤
  │ [+] 创建新 Agent        │
  │ 👤 user       🌙 🚪    │
  └─────────────────────────┘

  - 右上角新增 🤖 按钮 → 切换到 Agent 管理视图
  - 原有的 "+" 按钮行为改变 → 切换到添加 Agent 视图（不再是 Dialog）

  视图 2：添加会话（点击 "+" 后）

  ┌─────────────────────────┐
  │ ← 会话       + 添加     │ ← 顶部导航：返回 + 标题
  │ 🔍 搜索 Agent...        │ ← 搜索可用的 Agent
  │                         │
  │ [单聊]  [群聊]          │ ← 模式切换
  │                         │
  │ ☐  🤖 Agent A          │ ← 可滚动的 Agent 列表
  │ ☐  🤖 Agent B          │
  │ ☐  🤖 Agent C          │
  │ ☐  🤖 Agent D          │
  │ ☐  🤖 Agent E          │
  │ ...                    │
  │                         │
  │ 已选 2 个 Agent        │
  │ [ 创建群聊 (2) ]       │
  └─────────────────────────┘

  - 像微信添加联系人一样：左侧全屏展现所有可用 Agent
  - 有搜索框专门搜索 Agent
  - 单聊模式：点击 Agent 直接创建会话并跳转
  - 群聊模式：勾选多个，底部创建
  - 左上角 ← 返回会话列表

  视图 3：Agent 管理（点击 "🤖" 后）

  ┌─────────────────────────┐
  │ ← 会话     我的 Agent   │ ← 顶部导航：返回 + 标题
  │ 🔍 搜索我的 Agent...    │ ← 搜索已创建的 Agent
  │                         │
  │ ┌─────────────────────┐ │
  │ │ 🤖 Agent A          │ │
  │ │  能力标签 · 描述    │ │
  │ │                ✏️ 🗑️│ │ ← 编辑/删除
  │ └─────────────────────┘ │
  │ ┌─────────────────────┐ │
  │ │ 🤖 Agent B          │ │
  │ │  能力标签 · 描述    │ │
  │ │                ✏️ 🗑️│ │
  │ └─────────────────────┘ │
  │ ...                    │
  │                         │
  ├─────────────────────────┤
  │ [+] 创建新 Agent        │
  │ 👤 user       🌙 🚪    │
  └─────────────────────────┘

  - 显示所有你创建的 Agent，每张卡片包含头像、名称、描述、能力标签
  - 可对每个 Agent 进行编辑、删除操作
  - 底部保留「创建新 Agent」按钮

  ---
  视图导航逻辑

      ┌──────────┐ 点击 🤖    ┌──────────────┐
      │ 会话列表  │ ───────→  │ Agent 管理    │
      │ (默认)   │ ←───────  │ (浏览/编辑)   │
      └──────────┘  返回      └──────────────┘
           │
     点击 "+" │
           ↓
      ┌──────────┐
      │ 添加Agent│
      │ (选人建群)│
      └──────────┘

  三个视图之间通过 header 的按钮和「返回」切换，本质上是 Sidebar 内部的状态机。
