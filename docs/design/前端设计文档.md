## 序：设计哲学

### 审美方向
**编辑式极简（Editorial Minimalism）** — 灵感来自杂志排版和独立咖啡馆的视觉语言。温暖、有质感、不冰冷。

**核心选择逻辑：**
- 不使用冷灰 `/f5f5f5/`（太像工具类产品），改用暖灰 `#f4f3f0`（像纸的质感）
- 不使用 Inter（太泛滥），改用 DM Sans（几何但温暖）
- 不使用纯蓝色作为强调色，改用深墨色 `#1a1a2e`（更安静、更编辑感）

### 背景质感
页面背景不是纯色，是两个极淡的径向渐变叠加：
```css
background-image:
  radial-gradient(circle at 30% 50%, rgba(26,26,46,0.02), transparent 60%),
  radial-gradient(circle at 70% 80%, rgba(43,138,107,0.015), transparent 50%);
```
肉眼几乎看不出，但让"纯白"不是死白——增加了空间深度。

## 一、完整 CSS 变量体系

直接从 `设计稿-优化版.html` 提取：

```css
:root {
  /* ===== 背景色 ===== */
  --bg-page: #f4f3f0;          /* 页面背景：暖灰，非冷灰 */
  --bg-app: #ffffff;            /* 应用容器：纯白 */
  --bg-sidebar: #faf9f7;        /* 侧栏：比页面略白，形成层次 */
  --bg-hover: #f0efeb;          /* hover状态：暖灰 */
  --bg-active: #e8e6e1;         /* active状态：较深暖灰 */
  --bg-msg-agent: #f7f6f3;      /* Agent气泡：暖灰，让气泡"浮"在白色上 */
  --bg-user: #1a1a2e;           /* 用户气泡：深墨色 */
  --bg-code: #faf9f7;           /* 代码块背景 */

  /* ===== 边框 ===== */
  --border: #e6e4df;            /* 主要边框：暖灰 */
  --border-light: #eeede9;      /* 轻量边框（更细的线） */

  /* ===== 文字色 ===== */
  --text-primary: #1a1a2e;      /* 主要文字：深墨色，非纯黑 */
  --text-secondary: #7c7a76;    /* 次要文字：暖灰 */
  --text-tertiary: #b0aea8;     /* 辅助文字：浅灰 */

  /* ===== 语义色 ===== */
  --accent: #1a1a2e;            /* 强调色 = 深墨色，无彩色强调 */
  --accent-light: rgba(26,26,46,0.06); /* 强调色的透明版本（用在Tab active背景） */
  --green: #2b8a6b;             /* 成功/部署 */
  --green-bg: #edf7f3;          /* 成功背景 */
  --red: #c93a3a;               /* 危险/错误 */
  --amber: #b8860b;             /* 警告/Claude配色 */

  /* ===== 阴影 ===== */
  --shadow-sm: 0 1px 3px rgba(0,0,0,0.04);  /* 卡片轻微阴影 */
  --shadow-md: 0 4px 16px rgba(0,0,0,0.06); /* 卡片hover加深 */

  /* ===== 圆角体系 ===== */
  --radius-sm: 6px;             /* 按钮 */
  --radius-md: 10px;            /* 卡片 */
  --radius-lg: 16px;            /* 消息气泡 */
  --radius-xl: 20px;            /* 应用容器角 */

  /* ===== 字体 ===== */
  --font-sans: 'DM Sans', sans-serif;
  --font-mono: 'DM Mono', 'JetBrains Mono', monospace;
}
```

### 设计决策说明

| 变量 | 为什么是这个值 |
|------|--------------|
| `--bg-page: #f4f3f0` | 暖灰而非冷灰 `#f5f5f5`，因为 DM Sans 是 warm geometric，双方匹配。Inter + `#f5f5f5` 冷感太强，不适合IM工具 |
| `--text-primary: #1a1a2e` | 纯黑 `#000` 在白色背景上对比度太高，长时间阅读会疲劳。`#1a1a2e` 是深墨蓝色，柔和但有力量 |
| `--accent: #1a1a2e` | 不用蓝色做强调色。蓝色在IM产品里太容易被识别为链接/可点击元素。用深墨色作为主动作色，降低认知混淆 |
| `--radius-lg: 16px` | 气泡圆角跟飞书保持一致。圆角体系 `6→10→16→20` 来自钻石切割的倍数比例，不是随意定的 |
| `--shadow-sm: 0 1px 3px` | 极淡阴影。目标是"感觉不到阴影但有层次"，而非"有阴影" |


## 十、SSE 架构

```
POST /api/chat/send  { conversationId, content, agentId }
  ↓
服务端返回 { taskId }
  ↓ 同时
SSE GET /api/chat/stream/:conversationId
  ↓ 正常
event: message_chunk    → 流式渲染打字机效果
event: message_complete → 消息完成
event: error            → 错误信息
  ↓ 10s超时断开
客户端轮询 GET /api/chat/poll/:taskId
  (指数退避: 1s → 2s → 4s → 8s, 最多5次)
```

**前端状态机：**
```
connecting → streaming → done
                  ↓ (10s超时)
              polling → done
                  ↓ (5次失败)
                error
```

## 十五、流式消息渲染（打字机效果）

### Token 缓冲逻辑

```typescript
// 核心：不是一个个字显示，是以"语义块"为单位

interface StreamChunk {
  type: 'text' | 'code' | 'diff';
  content: string;
  append: boolean;   // true=追加到当前块, false=新块
}

// 缓冲策略
const buffer: StreamChunk[] = [];
let timer: NodeJS.Timeout;

function onChunkReceived(chunk: StreamChunk) {
  buffer.push(chunk);
  if (!timer) {
    timer = setInterval(flushBuffer, 50); // 50ms 刷新一次
  }
}

function flushBuffer() {
  const chunks = buffer.splice(0, 3); // 每次最多取3个
  // 追加到消息内容
  // React 更新
  if (buffer.length === 0) {
    clearInterval(timer);
    timer = null;
  }
}
```
