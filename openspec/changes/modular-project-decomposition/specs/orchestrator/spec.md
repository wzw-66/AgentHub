## 新增需求

### 需求：任务拆解
编排器应分析群聊消息，并将其拆解为独立的子任务。

#### 场景：将消息拆解为任务
- **当** 用户在群聊中发送一条提及多个 Agent 的消息
- **则** 编排器应基于意图分析将消息拆解为子任务

### 需求：并行任务分发
编排器应将独立的子任务并行分发给多个 Agent。

#### 场景：独立任务并行执行
- **当** 两个子任务之间没有依赖关系
- **则** 两者应通过 SSE 流同时分发执行

#### 场景：每个 Agent 拥有独立 SSE 流
- **当** 多个 Agent 并行执行
- **则** 每个 Agent 的输出应在独立的 SSE 通道上流式传输

### 需求：串行任务分发
编排器应按顺序执行具有依赖关系的子任务。

#### 场景：依赖任务串行执行
- **当** 子任务 B 依赖于子任务 A 的输出
- **则** 子任务 B 应等待子任务 A 完成后才能开始

### 需求：失败处理
编排器应优雅地处理 Agent 执行失败。

#### 场景：Agent 失败触发重试
- **当** Agent 执行期间失败
- **则** 编排器应在标记任务为失败前重试一次

#### 场景：失败任务不阻塞其他任务
- **当** 一个 Agent 失败
- **则** 其他并行 Agent 应不受影响继续执行

#### 场景：完成后聚合结果
- **当** 所有子任务完成（包括失败的）
- **则** 编排器应生成聚合摘要
