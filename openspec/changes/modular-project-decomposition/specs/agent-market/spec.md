## 新增需求

### 需求：Agent 列表页面
系统应显示可用 Agent 列表（内置和用户创建的）。

#### 场景：Agent 列表渲染
- **当** 用户导航到 `/agents`
- **则** 所有可用 Agent 应显示名称、头像和提供商

#### 场景：内置 Agent 优先显示
- **当** Agent 列表加载
- **则** 内置 Agent 应显示在用户创建的 Agent 之前

### 需求：Agent 详情页面
系统应显示特定 Agent 的详细信息。

#### 场景：Agent 详情渲染
- **当** 用户导航到 `/agents/:id`
- **则** 应显示 Agent 的名称、头像、提供商、模型和描述

#### 场景：从详情页开始聊天
- **当** 用户在 Agent 详情页点击"开始聊天"
- **则** 应使用该 Agent 创建新的单聊会话

### 需求：自定义 Agent 创建
系统应允许用户通过名称和系统提示词创建自定义 Agent。

#### 场景：创建自定义 Agent 表单
- **当** 用户填写创建 Agent 表单（名称、系统提示词、模型）
- **则** 应创建新的自定义 Agent

#### 场景：新 Agent 出现在列表中
- **当** 自定义 Agent 创建完成
- **则** 应立即出现在 Agent 列表中

### 需求：联系人管理
系统应允许用户管理其 Agent 联系人列表。

#### 场景：将 Agent 添加为联系人
- **当** 用户在 Agent 上点击"添加到联系人"
- **则** 该 Agent 应添加到用户的联系人列表

#### 场景：自定义联系人名称
- **当** 用户编辑联系人显示名称
- **则** 更改应反映在会话列表中

#### 场景：置顶/取消置顶联系人
- **当** 用户切换联系人的置顶状态
- **则** 置顶的联系人应显示在会话列表顶部
