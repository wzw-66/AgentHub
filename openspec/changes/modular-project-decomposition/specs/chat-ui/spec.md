## 新增需求

### 需求：三栏聊天布局
Web 应用应显示三栏 IM 布局：侧边栏、聊天面板和可选的右侧面板。

#### 场景：三栏布局渲染
- **当** 用户导航到 `/chat`
- **则** 应渲染侧边栏（w-72）、聊天面板（flex-1）和右侧面板（默认隐藏）

### 需求：带会话列表的侧边栏
侧边栏应显示用户信息、搜索框、会话列表和新建聊天按钮。

#### 场景：会话列表显示
- **当** 侧边栏加载
- **则** 会话项应显示头像、名称、最后消息预览和未读计数

#### 场景：搜索过滤会话
- **当** 用户在搜索框中输入
- **则** 会话列表应按名称过滤

#### 场景：新建聊天按钮
- **当** 用户点击新建聊天按钮
- **则** 应弹出对话框选择 Agent 并创建会话

### 需求：带气泡的消息列表
聊天面板应显示为气泡形式，按发送者区分样式。

#### 场景：用户消息气泡左对齐
- **当** 消息的 `senderType` 为 "user"
- **则** 应显示为左对齐气泡

#### 场景：Agent 消息气泡右对齐
- **当** 消息的 `senderType` 为 "contact"
- **则** 应显示为右对齐气泡

#### 场景：输入中状态指示器
- **当** Agent 正在输入/流式输出
- **则** 消息列表中应显示输入中状态指示器

#### 场景：系统消息居中显示
- **当** 消息的 `senderType` 为 "system"
- **则** 应显示为居中的系统通知

### 需求：带 @提及的聊天输入框
聊天输入框应支持文本输入，在群聊中支持 Agent @提及。

#### 场景：文本输入框存在
- **当** 聊天面板加载
- **则** 应渲染文本区域输入框和发送按钮

#### 场景：群聊中 @提及弹出框
- **当** 用户在群聊中输入 `@`
- **则** 应弹出框显示可提及的 Agent

#### 场景：按回车发送消息
- **当** 用户在输入框中按下回车键（不按 Shift）
- **则** 消息应发送

### 需求：会话头部
聊天面板应显示包含会话信息的头部。

#### 场景：头部显示名称和成员
- **当** 查看会话
- **则** 头部应显示会话标题和参与者名称
