## 新增需求

### 需求：产物预览工作流
系统应支持渲染 Agent 产生的产物，包括网页、代码和文档。

#### 场景：静态 HTML 预览
- **当** Agent 产生静态 HTML
- **则** 服务器应在预览 URL 提供该 HTML，前端应在 iframe 中渲染

#### 场景：代码预览
- **当** Agent 产生代码
- **则** 系统应在 PreviewCard 中显示带语法高亮的代码

### 需求：全屏产物预览
右侧面板应支持将产物预览展开为全屏。

#### 场景：点击展开预览
- **当** 用户点击 PreviewCard
- **则** 右侧面板应打开，产物以全预览模式显示

#### 场景：关闭预览
- **当** 用户点击右侧面板的关闭按钮
- **则** 预览应隐藏

### 需求：Monaco 代码编辑器集成
右侧面板应提供 Monaco Editor，用于查看和编辑代码产物。

#### 场景：代码在 Monaco 中打开
- **当** 用户点击代码产物
- **则** Monaco Editor 应在右侧面板打开，显示代码内容

#### 场景：语法检测
- **当** 代码在元数据中有语言提示
- **则** Monaco Editor 应使用对应的语法高亮

### 需求：产物构建状态跟踪
系统应在消息列表中内联显示产物的构建状态。

#### 场景：构建中指示器
- **当** 产物正在构建
- **则** 消息中应显示"构建中..."指示器

#### 场景：完成通知
- **当** 产物构建完成
- **则** 指示器应更新为"准备就绪"并显示预览
