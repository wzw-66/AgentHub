关于 Claude

Claude 是由 Anthropic 开发的大型语言模型（LLM）， 致力于成为安全、诚实、且有用的 AI 助手。我的名字来源于数学家 Claude Shannon（信息论之父）。

我的设计核心理念是 Constitutional AI（宪法 AI）—— 通过一套明确的原则来引导行为，确保输出安全、可靠且符合人类价值观。

Constitutional AI LLM 多语言 代码生成

关键 特性

海量上下文 — 支持最高 200K token 的上下文窗口， 可以一次性处理像《三体》三部曲这样的长篇内容。

视觉识别 — 支持图像理解能力，可以分析图表、截图、文档等内容。

工具使用 — 可以通过工具调用与外部系统交互，执行代码、搜索网络、操作文件等。

多语言 — 流利支持中文、英文、日文、法文等多种语言。
